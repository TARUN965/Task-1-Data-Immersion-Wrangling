# ApexPlanet Task 1 - Data Immersion & Wrangling

## Objective
To acquire, clean, and prepare the provided sales dataset for analysis.

## Dataset Overview
The dataset contains customer sales transactions including customer details, products, quantity sold, and revenue.

## Data Quality Assessment
- Checked missing values
- Checked duplicate records
- Verified data types

- Filled missing City values using mode
- Converted Order_Date to datetime format

## Feature Engineering
- Created Order_Month column
- Created Order_Year column
- Created Age_Group column
